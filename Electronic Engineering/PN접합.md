- P형과 N형을 붙인 것이 아닌 연속적으로 P층에서 N층으로 변해가는 구조를 이뤄 가능 구조를 이룬다. 도너나 억셉터를 혼합하여 결정의 일부분을 P형과 N형 영역으로 하여 접한 상태를 만들어내는 것이 PN접합이다.
- PN접합이 되면 P형의 정공은 N의 영역으로 확산에 의해 흐르고 자유전자는 N형→P형으로 흐름.

→ 이런 캐리어를 주입 캐리어라고 함

- 접합면의 P형 영역에서 정공이 유출하면 정전하가 흘러나간 것(고정된 전하의 영역이 줄은 것)이 되므로 이 P형 영역은 마이너스 전하의 성질을 가진 것이 됨(억셉터 이온만 남아서)
- P형과 N형의 접합 부분에서는 결핍한 영역이 생기는데, 이 영역은 자유전자와 정공의 이동을 막아 캐리어는 균형을 이룸
    - 이 영역을 공핍층 이라 부른다.
    - 공핍층을 통과하려면 전위구배가 올라가야 하는데 이 전위구배는 캐리어 이동을 방해함→전위 장벽
    - 전위 구배?
        
        전위가 달라지는 정도. 얼마나 빠르게 전압이 변하는지를 나타냄
        
        전위 구배가 크면 → 전압이 짧은 거리에서 급격히 변함
        
        전위 구배가 작으면 → 전압이 천천히 변함
        
- PN접합을 사용하는 이유? : 전위 장벽을 만들어 외부 에너지를 이용해 캐리어의 수를 제어하기 위해서임

## 순방향 바이어스

P형 → (+),  N형 → (-) 으로 전압을 가하는 것

- 순방향으로 전압을 가하면 P형 영역의 (-)전위장벽이 밀려올라가게 되고, N형 영역의 (+)장벽은 끌려 내려가기 때문에 전위의 장벽은 외부 전압에 따라 소실되어 거의 존재하지 않게 됨
- 그래서 자유전자(N→P)와 정공(P→N)이 쉽게 넘어갈 수 있게 되고 이걸 순방향 바이어스, 전류를 순방향 전류라고 함
- 바이어스?
    
    소자에 전압을 걸어 동작 방향과 세기를 결정하는 것
    
    바이어스를 걸었다 → PN접합이나 트랜지스터에 전원을 연결해서 동작 시키겠다.
    

## 역방향 바이어스

P형 → (-),  N형 → (+) 으로 전압을 가하는 것

- 역방향으로 전압을 가하면 전위장벽이 더 높아져 공핍층의 너비도 넓어진다.
    - 흐르는 캐리어가 극히 적어짐
    - 매우 적은 전류만 흐르게 됨
    - 이 상태를 역방향 바이어스라고 하고, 전류를 역방향 전류라고 한다.
