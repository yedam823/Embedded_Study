## 클리퍼

- 교류입력전압의 특정 전위값 이상이나 이하를 제한하는 회로
- 반파 정류기는 클리퍼 회로의 간단한 예(역방향 바이어스 제한)
- 다이오드 + 저항(+바이어스 전원), 다이오드 방향에 따라 입력 신호를 특정 전압 이하로 자름
- 파형 정형 및 과전압 보호에 사용됨

> 클리퍼의 종류
> 
1. 양의 반주기 클리퍼
- 다이오드 정방향 연결 → 양의 전압 제한
- 입력이 특정 전압보다 작을때 받음, 크면 다이오드 on되며 제한
1. 음의 반주기 클리퍼
- 다이오드 역방향 연결 → 음의 전압 제한
- 입력이 특정 전압보다 클때 받음, 작으면 다이오드 ON되며 제한
1. 바이어스 클리퍼
- 다이오드와 DC 바이어스 전원 조합 → 제한 전압 조정
- 예 : +2V 바이어스 → 2V 이상만 잘림
- 예 : -2V 바이어스 → -2V 이하만 잘림

## 클램퍼

입력 신호의 기준 전압 레벨을 이동시켜 출력 신호의 DC위치를 조정하는 회로

- 파형 모양 유지, DC 레벨만 위/아래 이동
- 구성 요소 : 다이오드 + 커패시터 + 부하 저항(+ 바이어스 전원)

> 동작 원리
> 

입력이 (-)일때 : 다이오드 ON → 커패시터 충전

입력이 (+)일때 : 다이오드 OFF → 커패시터 전압유지 → 파형 이동

결과 : 전체 파형이 DC 전압만큼 이동

> 클램퍼의 종류
> 

양의 클램퍼 : 최소값이 기준 전압(0V) 보다 크도록 파형을 위로 이동 시킴

음의 클램퍼 : 최대값이 기준 전압(0V) 보다 작도록 파형을 아래로 이동

바이어스 클램퍼 : DC 전원 추가 → 이동량 조정 가능
